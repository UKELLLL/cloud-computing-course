# Cloud Concepts Reflection

Cloud computing is part of my daily life because I use many online applications. Three cloud services that I regularly use are Google Drive, Facebook Messenger, and Canva.

Google Drive is a Software as a Service (SaaS) because I use it through a web browser or mobile app without installing or managing any servers. It uses the Public Cloud deployment model because it is available to anyone with a Google account.

Facebook Messenger is also a SaaS application since it allows users to send messages, make calls, and share files over the internet. It is also a Public Cloud service because millions of users access it online.

Canva is another SaaS application because it provides online tools for creating presentations, posters, and other graphic designs without requiring users to install professional software. Like the others, it uses the Public Cloud deployment model.

Git and GitHub are important when working on cloud projects because they help keep track of changes made to files and code. Version control allows developers to go back to previous versions if mistakes happen. GitHub also makes teamwork easier because multiple people can work on the same project without overwriting each other's work. Team members can review changes, suggest improvements, and collaborate more efficiently.

Overall, this activity helped me understand that cloud computing is already part of my everyday life. It also showed me that Git and GitHub are valuable tools for organizing projects and working with others. I look forward to learning more about cloud computing and applying these concepts in future activities and projects.
