# Reflection

This laboratory activity helped me understand the differences between AWS, Microsoft Azure, and Google Cloud Platform. I learned that the three cloud providers offer similar services for computing, storage, networking, databases, and other cloud needs, but they have different strengths and features.

One of the most useful parts of the activity was comparing equivalent services across the three platforms. For example, Amazon EC2, Azure Virtual Machines, and Google Compute Engine all provide virtual machine capabilities. I also learned about services such as Amazon S3, Azure Blob Storage, and Google Cloud Storage for object storage.

The client recommendation activity helped me understand that choosing a cloud provider depends on the specific needs of an organization. AWS can be a good choice for startups and global applications because of its wide range of services. Azure is suitable for organizations that already use Microsoft technologies, while Google Cloud is a strong option for Artificial Intelligence, Machine Learning, and Kubernetes workloads.

The KillerCoda activity also gave me hands-on experience with a Linux environment. I used commands such as `cat /etc/os-release`, `lscpu`, `free -h`, and `df -h` to identify the operating system, CPU, memory, and disk information of a Linux server.

Overall, this activity improved my understanding of multi-cloud environments and helped me see how cloud platforms can be selected based on business and technical requirements. It also showed me that cloud computing is not only about using one provider, but about understanding which platform and services are most appropriate for a particular situation.
